1. Create a binary or script prefixing argocd- . Example is given below.
vim argocd-test-plugin
#!/bin/bash

# Check if the argocd CLI is installed
if ! command -v argocd &> /dev/null; then
    echo "Error: Argo CD CLI (argocd) is not installed. Please install it first."
    exit 1
fi

if [[ "$1" == "version" ]]
then
    echo "I am a test plugin & displaying argocd version..."
    argocd version
    exit 0
fi


echo "I am a test plugin & displaying argocd version..."

2. Provide Execute permission to this binary.
adminuser@IN-CS7MR24:~/argocd/plugins$ chmod +x argocd-test-plugin
3. Move binary to the system path
adminuser@IN-CS7MR24:~/argocd/plugins$ sudo mv argocd-test-plugin /usr/local/bin/
4. test the plugin.
adminuser@IN-CS7MR24:~/argocd/plugins$ argocd test-plugin
I am a test plugin & displaying argocd version...
5. test with plugin arguments.
adminuser@IN-CS7MR24:~/argocd/plugins$ argocd test-plugin version
